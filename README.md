# SiteGround 主机台账

一个可在浏览器中直接打开的单文件 HTML 工具，用于维护 SiteGround 账号、主机套餐、网站归属和付款记录。支持按套餐查看网站和付款，以及使用 JSON 备份、恢复和交接数据。

## 快速开始

1. 下载 [index.html](./index.html)，用桌面版 Chrome 或 Edge 打开。页面可离线使用。
2. 还没有保存过数据时，台账为空。已有备份可点击「导入 JSON」，选中备份文件并确认导入。从零录入时，先在「账号总览」新增账号，再添加主机套餐、网站和付款记录。
3. 编辑完成后点击「保存」。

## 保存与备份

- **自动保存**：浏览器允许写入本地存储时，导入的数据和后续修改会保存在当前浏览器中。更换电脑或浏览器、清理浏览器数据前，请先点击「导出 JSON」。
- **临时模式**：如果浏览器无法写入本地存储，页面仍可导入、查看、编辑和导出数据。看到临时模式提示时，**请在刷新或关闭页面前导出 JSON**。下次打开后，用导出的文件恢复。
- **恢复备份**：导入 JSON 会替换当前台账的全部记录。需要保留当前记录时，请先导出一份备份。

## 台账结构

| 页面 | 记录与用途 |
| --- | --- |
| 主机总览 | 记录套餐、所属账号和到期日，展示旗下网站和最近一笔付款。点击网站数或付款笔数可跳转到该套餐的明细。 |
| 网站清单 | 记录域名及所属套餐，支持按主机套餐筛选。 |
| 付款记录 | 记录付款日期、交易类型、购买周期、实付金额、币种及可选的发票编号或归档位置。 |
| 账号总览 | 记录账号编号、登录邮箱、登记公司、登记电话及可选的加密密码。 |

账号编号示例为 `SG-01`，其第一个套餐可编号为 `SG-01-P01`。一个账号可以关联多个套餐，网站和付款记录分别关联到对应套餐。

## 凭证与仓库文件

「加密密码」字段只填写已在外部加密的单行密文。页面会原样保存填入的内容，并随 JSON 一起导出。眼睛按钮可显示或隐藏密文。解密信息通过单独渠道交给授权接收人。

仓库中保存空白版 HTML 和本说明。包含真实账号、联系方式、付款记录或密码密文的 JSON，以及主机后台截图，应存放在仓库目录之外。

## 导出公司交接版

1. 从当前台账导出一份完整 JSON，供自己留存。
2. 如台账混有个人客户资料，先删除该客户关联的网站和付款记录，再删除套餐，最后删除账号。
3. 重新导出 JSON，核对只包含交接范围内的账号、套餐、网站和付款记录。
4. 将 `index.html` 和核对后的 JSON 提供给授权接收人。接收人打开 `index.html` 后，点击「导入 JSON」即可查看。
